# Techyy

Techyy is a responsive, static electronics storefront prototype. Open `index.html` in a browser to try it.

## Included

- Browse, search, sort, and filter sample electronics
- Switch between buy and rent, with rental length in the cart
- Local demo account screens, favourites, and shopping bag
- Admin workspace to add/remove products and upload a UPI QR image
- Demo checkout that displays the uploaded QR but does not collect payment

The prototype stores its data in this browser's `localStorage`. It has no server, secure admin login, inventory database, or payment integration; do not use it to process real orders. Product photography and fonts load from external image/font hosts.
